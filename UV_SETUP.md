# Reproducible environment with Astral uv

The project is set up as a **uv project**. The important portable files are:

- `pyproject.toml` — declares Python and package requirements
- `.python-version` — requests Python 3.12
- `uv.lock` — generated by `uv sync` / `uv lock` and should be committed to GitHub

Do **not** copy `.venv` from macOS to Windows. A virtual environment contains platform-specific paths and executables.

## On the development laptop

Install uv, then from the repository directory run:

```bash
uv sync
uv run python -m unittest discover -s tests -v
uv run gsc02c-ui
```

The first `uv sync` resolves dependencies, creates `.venv`, and generates `uv.lock` if it does not already exist. Commit `uv.lock` to GitHub.

## On the Windows lab computer

Clone or download the same GitHub repository. Then in PowerShell:

```powershell
uv sync --locked
uv run gsc02c-ui
```

`uv sync --locked` uses the committed lockfile and creates a Windows-specific `.venv` with the same resolved project dependencies.

You can also run:

```powershell
.\setup_windows.ps1
```

for the setup/test sequence, and later double-click `run_ui_windows.bat` to launch the GUI once `uv` is installed.
